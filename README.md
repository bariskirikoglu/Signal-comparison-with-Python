
# Signal Comparison with Python

This project demonstrates basic signal visualization using Python.

## Overview

The main purpose of this project is to understand how signals with different frequencies behave over time and how they combine with each other.

## Features

- Generation of sine waves with different frequencies  
- Visualization of signals in the time domain  
- Superposition (combination) of multiple signals  

## Technologies Used

- Python  
- NumPy  
- Matplotlib  

## What I Learned

- Basics of signal representation  
- How different frequencies affect signal behavior  
- Visualization of mathematical functions using Python
